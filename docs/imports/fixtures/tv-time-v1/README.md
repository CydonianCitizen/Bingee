# Synthetic TV Time v1 fixture

All values in this directory are independently synthetic. The fixture preserves only grammar verified from private sample TVTIME-SAMPLE-001: three JSON top-level arrays with list, movie-like, and series/episode roles, nullable watched timestamps, source relationships, season zero, specials, high season numbers, empty episode arrays, Unicode, commas, and quotes.

The filenames are safe fixture labels, not copied source filenames. This fixture is not evidence for any other TV Time export variant.
