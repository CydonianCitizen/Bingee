# ADR 0004: License the project under Apache License 2.0

- Status: Accepted
- Date: 2026-07-31

## Context

Bingee is intended for open-source collaboration and needs a clear license covering use, modification, redistribution, and patent rights.

## Decision

Distribute the project under Apache License 2.0. Contributions accepted into the repository are distributed under the same license unless explicitly stated otherwise.

## Consequences

- Users and contributors receive a permissive license with an explicit patent grant.
- Redistributors must preserve the license and applicable notices.
- Third-party dependencies and assets still require separate license compatibility and attribution checks.
